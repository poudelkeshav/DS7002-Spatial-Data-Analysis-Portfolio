# DS7002-Spatial-Data-Analysis-Portfolio

Comprehensive spatial data analysis portfolio exploring GIS techniques, spatial statistics, urban analytics, transport accessibility, hotspot analysis, and spatial regression using London-based datasets.

---

## Project Overview

This repository contains a complete spatial data analysis portfolio developed for the DS7002 Spatial Data Analysis module at the University of East London. The portfolio demonstrates practical applications of Geographic Information Systems (GIS), geostatistics, spatial SQL, remote sensing, hotspot analysis, accessibility modelling, spatial autocorrelation, and spatial regression using real-world London datasets.

The project applies multiple spatial analytical techniques to examine urban patterns related to crime, transport infrastructure, healthcare accessibility, deprivation, population distribution, and environmental characteristics across London boroughs and Haringey.

The portfolio combines practical GIS workflows, statistical interpretation, map-based visualisation, and critical discussion to demonstrate understanding of spatial thinking and spatial decision-making in urban analysis.
